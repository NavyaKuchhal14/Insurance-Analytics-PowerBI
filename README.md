# Insurance Analytics Dashboard — Power BI

## Project Overview
Analyzed 10,000 insurance policies to uncover claim rejection patterns 
and customer sentiment insights using Power BI and NLP.

## Key Insights
- 44% of claims were Rejected — highest claim status in the dataset
- Travel policies generated the highest premium (₹2.5M) but also highest rejections
- Adults filed ₹8.8M in claims vs ₹1.7M from Elders
- Sentiment analysis: 54 "Needs Improvement" vs 43 "Excellent" customer reviews
- Top complaint themes: confusing terms, lengthy processes, unclear policies

## Tools Used
Power BI · DAX · Power Query · NLP Sentiment Analysis

## Dashboard Pages
1. Main KPI Dashboard — Premium, Coverage, Claims, Policy Type breakdown
2. Sentiment Analysis Page — Word cloud, customer feedback scores, feedback classification

## Dataset
10,000 rows · 12 columns · Insurance policy and claims data
